# Skill: UX Evaluation

## Purpose
Evaluate a flow or interface for task success, usability, clarity, and friction.

## When to use
Run iteratively while designing or building. For a final checkpoint, use **design-review.md**.

## Procedure
1. Start from the user's goal.
2. Walk the complete flow from entry to successful outcome.
3. Check whether the next action is obvious.
4. Check hierarchy and terminology.
5. Check mental-model alignment.
6. Check system status and feedback.
7. Check error prevention and recovery.
8. Check unnecessary steps and repeated work.
9. Check discoverability at the moment information is needed.
10. Check keyboard, responsive, and accessibility implications.
11. Rank findings by impact.

## Heuristic questions
- Is the current state obvious?
- Does the interface speak the user's language?
- Does it match familiar conventions?
- Can the user undo or recover?
- Are avoidable errors prevented?
- Is important information visible without forcing memory?
- Is there unnecessary cognitive or interaction cost?

## Output
For each finding: severity / location / observed issue / user impact / principle / recommendation / confidence.
Use evidence from the actual interface whenever possible.
